# Iris Classification using KNN, Logistic Regression and Naive Bayes

## Overview

This mini project implements classification on the Iris dataset using multiple Machine Learning algorithms.

The objective is to classify iris flowers into different species based on their features and compare the performance of different classification models.

---

## Dataset

Dataset: Iris Dataset

Features used:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

---

## Workflow

1. Load Iris dataset
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Train-test split
5. Model training
6. Model evaluation
7. Comparison of classification algorithms

---

## Models Used

### K-Nearest Neighbors (KNN)
Classification based on nearest neighbors.

### Logistic Regression
Linear classification model used for multi-class classification.

### Naive Bayes
Probabilistic classifier based on Bayes theorem.

## Evaluation Metrics

Models evaluated using:

- Accuracy Score

## Result

Performance comparison was carried out among:

- KNN

to identify the best performing classifier for the Iris dataset.
